# 源码打包说明
可以直接下载最新代码，进行打包，最新代码相比已经发布的安装包可能会包含最新的特性

## 环境要求
* maven 3.6+
* jdk 17+（最低JDK 17）
* Node.js >= v24.13.0（构建前端需要，deploy profile 会自动下载 Node.js v24.13.0 和 npm 11.6.2）
* git（非必须）  

maven是建议版本>=3.6版本，3.4+和3.5+我也没试过，3.3+的版本，在windows上我试了下打包有bug，可能把spring boot的application.yml打不到合适的目录。

如果3.6+在mac上也不行（也是上面这个问题），建议用最新版本试试。

## 源码下载
```
git clone https://github.com/xxd763795151/kafka-console-ui.git
```
或者直接在页面下载源码

## 打包
我已经写了个简单的打包脚本，直接执行即可。
### Windows
```
cd kafka-console-ui
# windows执行
package.bat
```
### Linux或Mac OS
```
cd kafka-console-ui
# linux或mac执行
sh package.sh
```  

打包完成，会在 target 目录下生成 `kafka-console-ui-<版本>.zip` 和 `kafka-console-ui-<版本>.tar.gz` 安装包。

### 打包流程说明
deploy profile 使用 frontend-maven-plugin 自动完成：
1. 下载 Node.js v24.13.0 和 npm 11.6.2
2. 执行 `npm install` 安装前端依赖
3. 执行 `npm run build` 构建 Vue3 + TypeScript 前端产物
4. 将 ui/dist 下的静态文件拷贝到 target/classes/public 目录
5. 最后打包为发布 zip 和 tar.gz 包
